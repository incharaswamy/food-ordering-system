# Online Food Ordering System

## Description
A web-based application using PHP and MySQL where users can register, login, select food items, add to cart, and place orders.

## Features
- User Registration & Login
- Food Selection (Multiple items)
- Cart System
- Order Storage in Database

## Technologies Used
- PHP
- MySQL
- HTML

## How to Run
1. Start Apache and MySQL in XAMPP
2. Create database `food_ordering` in phpMyAdmin
3. Run the SQL tables
4. Open http://localhost/food_ordering
